multi-agent-task-handoff — 多 agent 任务交接

用法:
  multi-agent-task-handoff [--workspace <PATH>] [--nosave] [--help | --resume | --suspend [--local | --commit | --push] | --post <message> [--new | --next <ID | 会话名>] | --doc | --check | --fix | --probe [--static | --live] | --printpath [--host NAME | --target DIR]]

命令:
  --resume                  接盘 / 接手：读 handoff/PROMPT.md → handoff/CONTEXT.md，
                            冲突以 CONTEXT 为准；核锚点、跑验证
  --suspend [--local | --commit | --push]
                            压卡（按需）+ 收工 + 写 handoff/PROMPT.md
                              --local   只写卡与 PROMPT，不操作 git
                              --commit  提交协议管理文档（含 --doc 的移动/删除）
                              --push    提交并推送（隐含 commit；网络错误重试 3 次，间隔 3 秒；
                                        Windows 再加 HTTP/1.1 + OpenSSL 回退 3 次）
                            默认挡位读 config.toml 的 [defaults].suspend
  --post <message> [--new | --next <ID | 会话名>]
                            投递 / 热交接：把 message 投给另一个会话；不写卡、不动 git
                              --new     新建会话后投递（必须绑定当前项目目录，落 worktree 视为失败）
                              --next <ID | 会话名> 投递到已有会话
                            默认读 config.toml 的 [defaults].post（new / next）
  --doc                     文档整理：建档、分类、迁移、补标记；拿不准给选项
  --check                   自检 / 更新：只读检查，报告 ✅ / 🟡 / ⛔
  --fix                     修复：只修安装/配置等非文档整理项，不碰文档增删迁移
  --probe [--static | --live]  摸底 / 探测：先检查，再实测当前 agent 并更新能力表
                              --static 只做静态检查与低成本实测
                              --live  实际执行建会话 / 发送 / 读回（需确认）
                            默认挡位读 config.toml 的 [defaults].probe
  --printpath [--host NAME | --target DIR]
                            路径诊断：表格输出配置目录 / 配置文件 / 工作区根 / 能力表
                            （含更新日期）/ 安装注册表 / 源仓库 / 宿主 / 当前安装副本 /
                            全部副本的路径与 commit；--host / --target 显式指定
  --workspace <PATH> [--nosave]
                            全局：指定工作区根；默认写回 config.toml；
                            --nosave 只本次生效，不写回
  --help                    显示本表

规则:
  一次只用一个命令；不支持命令叠加
  --workspace 可与一个命令同用；--nosave 只跟 --workspace
  --local / --commit / --push 只能跟 --suspend
  --new / --next 只能跟 --post；两者不能同时用；message 必填
  --live 只能跟 --probe
  --printpath 是独立命令；--host / --target 只能跟 --printpath
  --help 单独使用
  无参数等同 --resume

中文别名:
  接盘/接手、压卡/收工/交接、投递/热交接、工程化/工程/建档、自检/更新、修复、
  摸底/探测、路径诊断、帮助

样例:
  --workspace D:/agent_workspace --resume
  --workspace "C:/My Workspace" --resume
  --suspend --commit
  --post "接手 V4 文档布局，先读 handoff/PROMPT.md" --next <ID | 会话名>
  --post "接手 V4 文档布局" --new
  --fix
  --probe --live
  --doc
  --printpath

路径诊断:
  优先用 --printpath（表格输出）；脚本 / CI 可跑 scripts/handoff.sh --printpath；安装用 install.sh
