# 能力探测清单（--probe）

> 用途：固定 `--probe` 的测试矩阵，保证不同 agent 覆盖一致、不反复确认、未测项显式化。
> 读取方：agent；`--probe` 默认挡位读 `config.toml` 的 `[defaults].probe`（static / live）。
> 规则：static 只填 S 项；live 跑 S + L1 + L2。K 项只核对版本/日期，不重复破坏性操作。
> 最近更新：2026-11-09

## 级别

| 级别 | 含义 | 本次是否必跑 |
|---|---|---|
| S | 零测试副作用：读配置、列工具、静态检查 | 是 |
| L1 | 通道往返：唯一 PONG 串发出去、读回来 | live 必跑 |
| L2 | 真接盘：临时项目 + PROMPT/CONTEXT + 5 项核对 | live 必跑 |
| K | 已知破坏性结论（落 worktree、无会话列表等） | 只核对版本/日期 |
| N/A | 宿主无此概念 | 记原因 |

## §0 计划与一次性确认

`--probe --live` 开始先输出：

1. 本次要跑的 P 项。
2. 不跑的 P 项与理由（N/A / 宿主限制 / K 复用）。
3. 副作用：临时项目路径、要建的临时会话/teammate、要发送的消息。
4. 清理：删临时项目、测试会话/teammate、临时文件；删不掉只报告残留。
5. 将写能力表的行/列。

用户确认一次后按计划全量执行；只有计划外副作用（新权限、无法清理的持久对象、影响真实项目）才停下再确认。

## §2 live 项（L1 / L2）

> 每次 live 都跑 L1 与 L2；宿主确实无法执行某项时记 ⛔/🟡 + 原样错误，不能留“待测”。

| ID | 目标表/列 | 级别 | 动作 | 通过证据 | 清理 |
|---|---|---|---|---|---|
| L101 | 投递与读回 · 投递/读回 | L1 | 投唯一串 `PONG-<ts>`，读回原串 | 字符串逐字一致 | 删测试会话 |
| L102 | 项目目录操作 · 建会话 | L1 | 建临时会话 / teammate | 创建成功且可识别 | 删除 |
| L103 | 项目目录操作 · 新建会话并绑定目录 | L2 | 新建会话绑定临时项目，读回实际 cwd | cwd == 临时项目，且非 worktree | 删会话 |
| L104 | 项目目录操作 · 当前会话切目录 | L2 | 切换当前会话目录（无工具记 ⛔） | 切换后 cwd 变化 | 切回 |
| L105 | 项目/宿主术语 · 是否随 `cd` 变 | L2 | 在临时项目内 `cd` 子目录 | 项目目录不变 | 无 |
| L106 | 项目目录操作 · 文件迁移 | L2 | 临时项目内移动/复制一个临时文件 | 文件位置正确 | 删临时文件 |
| L107 | memory 读取 · suspend 读取 | L2 | 只读读取 memory 索引 | 读到内容或确认为空 | 无 |
| L108 | 能力矩阵 · 读 AGENTS/CONTEXT | L2 | 目标会话读临时 `PROMPT.md` / `CONTEXT.md` | 能读出内容 | 删会话 |
| L201 | 投递与读回 · 读回状态（真接盘） | L2 | 投临时 PROMPT 指针；目标读 PROMPT → CONTEXT，回报项目目录 / 锚点 / 下一步 / 勿动 / MEMORY 提炼 | 5/5 逐字一致 | 删会话 |
| L202 | 项目目录操作 · 绑定证据 | L2 | 目标读临时哨兵文件 | 内容一致 | 删会话 |

## §3 已知结论（K）

| ID | 场景 | 处理 |
|---|---|---|
| K01 | Claude `--new` 落 worktree | 版本未变且 30 天内复用；不重复破坏性建会话 |
| K02 | WorkBuddy `--next` 无会话列表 | 复用；L2 改用已有/手工会话 |
| K03 | fork / worktree 是否独立 | 复用；版本变化重测 |
| K04 | UI 打开目录 / 会话搬运 / 策略阻止 | 复用；状态记 ⛔/🟡 + 证据 |

> K 项不替代 L1/L2；版本变化或超 30 天时重测对应项。

## §4 清理与残留

- 删除临时项目、测试会话 / teammate、临时消息。
- 删除失败：报告残留对象与清理方法，不写真实 ID。
- 测试期间不修改真实项目的 `handoff/`，不写 git。

## §5 写表与完成核对

- 只就地更新 `$AGENT_CONFIG/AGENT_CAPABILITIES.md`，不追加行。
- 状态：`✅` / `🟡` / `🔴` / `⛔` / `—`（不适用，写原因）。
- 投递/读回状态写 `✅ L2（5/5）`、`🟡 L1`、`⛔`；L1 通过不得写 ✅。
- 当前宿主所有 S / L 必测格不得留“待测”；工具缺失/策略阻止记 ⛔/🟡 + 原样错误。
- 未安装宿主（Codex / VS Code 等）整行可留“待测”。
- 完成前逐项核对本表，缺失项写进报告。
