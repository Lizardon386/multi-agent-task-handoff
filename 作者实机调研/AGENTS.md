# 工作目录约定（工作区根）

> **作者实机调研快照，仅供参考。** 路径、账号、宿主版本均为作者本机环境，不代表通用约定；源文件在工作区根，更新以源文件为准（快照日期 2026-10-29）。

> 最近更新：2026-10-29
> 工作区根 = `$AGENT_WORKSPACE`；未设置时用 `D:\agent_workspace`（本机默认）。

- 工作区根是 agent 的工作产物根目录：会话产生的代码、文档、脚本、安装包、校验文件、导出数据等，一律放在工作区根下，按任务建子目录（`<工作区根>/<任务名>/`）。
- 不要把产物散落到其他盘符、用户目录或会话临时目录；拷入/拷出外部设备时以工作区根为中转。
- 会话临时目录是易失容器，不作为产物归宿。
- 不要手动搬动 agent 应用内部缓存（如 `~/.qoder-cn` 下的 memory、projects、.cache、logs）；本约定只约束工作产物。
- 已有同主题项目时，新工作用不同子目录区分，不覆盖既有产物；仓库源码的修改跟随各仓库自身规范。
- 读文档顺序：`PROJECT_RULES.md`（跨任务规则）→ 任务目录的 `CONTEXT.md`（状态）；需要投递/读回时再查 `AGENT_CAPABILITIES.md`（能力缓存）。
- 换机/交接：复制本文件、`PROJECT_RULES.md`、`AGENT_CAPABILITIES.md`；设置 `AGENT_WORKSPACE`；先按能力表的低成本项复验，再开工。
